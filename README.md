# 🚀 AI Web Applications

This repository contains two completed web application projects developed as part of my learning and internship journey.

## 📁 Projects Included

### 1. 🧠 Quiz App

An interactive quiz application where users can attempt questions and view their results.

**Key Features:**

- ❓ Multiple quiz questions
- ✅ Answer selection
- 📊 Score/result display
- 🔄 Option to restart the quiz
- 📱 Responsive user interface

📂 Project Folder: `quiz_app`

---

### 2. 🎯 Skill Gap App

A web application designed to help users identify the gap between their current skills and the skills required for their desired role or career goal.

**Key Features:**

- 👤 User skill input
- 💼 Role/career-based skill comparison
- 🔍 Skill gap identification
- 💡 Helpful learning recommendations
- 📱 Clean and responsive interface

📂 Project Folder: `skill_gap`

---

## 🛠️ How to Run the Projects

1. Clone this repository:

```bash
git clone https://github.com/noor-alishba/IQ_Web_Project.git
```

2. Open the project folder:

```bash
cd IQ_Web_Project
```

3. Go to the project you want to run:

```bash
cd quiz_app
```

or:

```bash
cd skill_gap
```

4. Install dependencies:

```bash
npm install
```

5. Start the project:

```bash
npm run dev
```

## 🔐 Environment Variables

If a project requires environment variables, create a `.env` file inside that project's folder and add your own values.

> `.env` files are not included in this repository to keep private information secure.
